### Two tool families

Node names tell you which family you are looking at:

- **Core** — the general-purpose Vonk toolset (3D, Array, Base64, CBOR, Color, FileSystem, Gradient, Guide, Image, JSON, Matrix, Meta, MTLX, Number, Point, ScriptVal, Shape, Text, USD, Vector, YAML). This is the original toolset.
- **Mograph** — a newer, more focused set of `vArray`/`vJSON`/`vMatrix`/etc. nodes purpose-built for motion-graphics pipelines (Array, HTML, JSON, Matrix, Number, ScriptVal).

Every node is prefixed by the data type it works with — `vArray*`, `vJSON*`, `vMatrix*`, `vText*` — which is also how you would search for it in Fusion's own **Select Tool** dialog (Shift+Spacebar). That naming convention is why the reference is organized by data type first.
