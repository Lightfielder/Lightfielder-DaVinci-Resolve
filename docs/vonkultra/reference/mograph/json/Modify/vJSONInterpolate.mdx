# vJSONInterpolate

Interpolate between corresponding values in two arrays Select Easing options include: - linear - easeInQuad - easeOutQuad - easeInOutQuad - easeInExpo - easeOutExpo - easeInOutExpo Match Array options include: - Trim Array to match - Add Zeros to match
