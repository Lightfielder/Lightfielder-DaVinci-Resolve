# vArrayDataComposite

Passes an image through unchanged while forcing one or two connected Array data branches to cook every frame the image is required — even though their values never touch the pixels. Use it to make a side-effect node (e.g. an Array writer) execute on every frame instead of only while its own Viewer is focused.
