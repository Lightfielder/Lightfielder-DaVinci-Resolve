# vJSONFromNet

Reads a JSON string from a network URL The network-based JSON resource downloading functionality provided by this node makes it possible to drive a composite from an external cloud based datasource. This means IoT (Internet of Things) electronic sensors, sports statistics, financial data, or any other web enabled datasource can be used on-the-fly to supply Text, Number, Matrix, Array, or other values to nodes in the comp.
