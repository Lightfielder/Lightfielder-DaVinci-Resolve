# vUSDWireless

Create wireless links between Fusion OpenUSD scenegraph objects The vUSDWireless node allows you to connect to other USD based nodes in your comp without drawing the connection wirelines visually in the Flow/Nodes view. This can be helpful if you need to reduce clutter.
