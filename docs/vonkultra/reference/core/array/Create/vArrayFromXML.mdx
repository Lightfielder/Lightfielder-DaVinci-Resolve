# vArrayFromXML

Creates a JSON array from XML The vArrayFromXML node works with XML formatted plain-text data. The XML data is read from a "vTextFromFile", "vTextFromNet", or "vTextFromZip" node. The output from the vArrayFromXML node is a text data type. The XML records are converted on-the-fly and stored in a JSON based array structure. This JSON array formatted data can be navigated and extracted using the Vonk provided "vArray" nodes like the "vArrayGetElement" node.
