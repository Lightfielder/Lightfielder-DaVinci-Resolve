# vNumberRange

Creates a Fusion Number object The range node creates a list of numbers that vary between the "From" and "To" values. The "Step" control increases the incremental rate of change in the output. If the "From" value was set to 0, and the "To" value was set to 5 the output from the node would be formatted like: \[0,1,2,3,4,5\]
