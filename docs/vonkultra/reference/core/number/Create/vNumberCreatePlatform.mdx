# vNumberCreatePlatform

Creates a unique Fusion Number object per OS platform If the fuse is rendered on a macOS system a value of 1 is returned. If the fuse is rendered on a Windows system a value of 2 is returned. If the fuse is rendered on a Linux system a value of 3 is returned.
