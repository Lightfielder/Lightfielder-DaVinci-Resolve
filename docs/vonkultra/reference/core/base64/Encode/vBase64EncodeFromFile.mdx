# vBase64EncodeFromFile

Base64 encodes a file into a Fusion Text object. This node converts the contents of an external file into a Base64 format. This can help with tasks like creating PNG format imagery that can be embedded inside a Fuse GUI as a block of base64 encoded data. The "File" input field is used to specify the filepath to a document.
