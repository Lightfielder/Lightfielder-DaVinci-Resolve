# vBase64DecodeFromText

Base64 decodes text from a Fusion Text object. A Base64 formatted block of text is converted back into plain ASCII text that can be passed downstream via a text data type. The "Text" field is used to specify a block of text that is currently Base64 encoded. The "Show Input" checkbox allows you to source the Text information from an external Text based data node connection.
