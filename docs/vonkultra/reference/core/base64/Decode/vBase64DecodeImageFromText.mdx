# vBase64DecodeImageFromText

Base64 decodes an image from a Fusion Text object. This node extracts a Base64 encoded image resource. A Base64 formatted image is extracted from a block of text, and converted into an image data type that can be displayed in the Fusion viewer window context. The "Text" field is used to specify a block of text that holds Base64 encoded image data. The "Show Input" checkbox allows you to source the Text information from an external Text based data node connection.
