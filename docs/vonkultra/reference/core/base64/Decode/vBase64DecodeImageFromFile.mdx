# vBase64DecodeImageFromFile

Base64 decodes an image into a file. A Base64 encoded image is extracted from an external file, and converted into an image data type that can be displayed in the Fusion viewer window context. The "Input" field is used to specify the filepath to an image that is currently Base64 encoded.
