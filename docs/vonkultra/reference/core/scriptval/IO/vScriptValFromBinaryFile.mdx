# vScriptValFromBinaryFile

Reads a Fusion ScriptVal blob encoded object from a binary file The binary file data is Base64 encoded and placed in a Lua table structure. A sample output from this encoding process looks like: \{ Base64 = "SGVsbG8gV29ybGQh", Base64Size = 16, BinarySize = 12, Ext = ".txt", Filename = "Hello.txt" Source = "/Users/vfx/Desktop/Hello.txt", Type = "File", \}
