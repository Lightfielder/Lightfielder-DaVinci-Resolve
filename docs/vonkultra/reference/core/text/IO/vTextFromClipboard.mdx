# vTextFromClipboard

Grabs the current clipboard text The "Sort List" checkbox works on a line-by-line basis to alphabetically sort the results generated by the node. The "Remove Quotes" checkbox is used to strip out any quote symbols found in the clipboard text. This is useful if you are trying to make an IFL like list and the source text was added to the clipboard buffer using the Windows "File Explorer" right-click based "Copy as path" contextual menu item. This node works on Windows, macOS, and Linux.
