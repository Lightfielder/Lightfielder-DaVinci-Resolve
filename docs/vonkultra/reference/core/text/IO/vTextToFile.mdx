# vTextToFile

Writes a Text string to a file The "Input" text-field holds the textual content that is saved to disk. The "File" text-field specifies the filename for the document. Both of these controls can be driven externally by enabling the "Show Input" checkbox. You would then connect vTextCreate or vTextSubFormat like text based data nodes to the input connections on the vTextToFile node.
