# vTextOrderReverse

Reverses the order of a Fusion Text object The "Text" field contents will be output letter-by-letter in a right-to-left mirrored fashion that reverses the text's placement. If you typed in "Hello Shuffle World!" the output would be "!dlroW elffuhS olleH".
