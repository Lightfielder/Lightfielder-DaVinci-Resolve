# vTextParseFilename

Creates a Fusion Text object by parsing a filepath The "Text" input field supports a filepath style of string that contains absolute or relative filepaths (including the use of Fusion PathMaps). The "Parse" ComboControl entries include: "FullPath", "FullPathMap", "Path", "PathMap", "FullName", "Name", "CleanName", "SNum", "Number", "Extension", "Padding", "UNC", and "Path + Name".
