# vTextNormalizeSlashes

Unifies the slash direction on filepaths The "Slash Direction" multi-button control allows you to choose if you want Windows (\\) or Linux (/) style slashes for your output text. The "Remove Duplicate Slashes" checkbox will replace any occurrence for two adjacent slashes with a single slash. This option is something you might not want to use if UNC file paths are common in filenames used in your pipeline.
