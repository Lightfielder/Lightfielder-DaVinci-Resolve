# vTextUUIDStatic

Creates a UUID Fusion Text object A static non-animated UUID (Universally Unique IDentifier) value is generated by this node. This value can be used to help with naming temporary items on disk, or for other tasks where an incrementing index based identifier is not appropriate. A UUID value is formatted like: `11625315-7785-4eb4-8b2f-d6dca235c424`
