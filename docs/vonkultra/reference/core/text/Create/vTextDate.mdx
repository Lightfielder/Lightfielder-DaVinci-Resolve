# vTextDate

Creates a date and time based Fusion Text object The "Text" field is used to enter the string formatting pattern used to generate a date based output. The default value is "`%Y-%m-%d`" which creates a result like "2022-05-24". The Lua documentation on the [Date function](https://www.lua.org/pil/22.1.html) provides more details about the supported values you can enter into the Text field in this node.
