# vTextEnv

Creates an environment variable based Fusion Text object This node will read an environment variable and return the result as a string. This is useful if you need to access a value like a SITE, SHOW, or SHOT env variable inside your composite. The "Text" field is used to enter the environment variable name like "PATH", "HOME", "USER", etc... If you need to troubleshoot the active environment variables on your Windows system using the Command Prompt you can type in "set". In the macOS/Linux terminal program you can type in "env \| sort" to see an alphabetically sorted list of the active environment variables.
