# vTextCreateMultiline

Creates a multi-line Fusion Text object The "Text" field supports entering multi-line text blocks that can include indentation, tabs, newlines, returns and other plain-text formatting variations. If you need to view this multi-line text based content downstream in the comp, try the vTextViewer node. This node is especially useful if you needed to create the original textual contents used for a shell script that you would save to disk using the vTextToFile node, and then run with a vTextProcessOpen node.
