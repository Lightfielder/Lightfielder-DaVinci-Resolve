# vTextFromNumber

Converts a number to text This node takes a number based input value that is converted automatically into a Text data type on the output. This makes it possible to supply a numerical value to a node like vTextSubFormat that only works with Text based inputs. The "Number" field holds the source numerical value. If the "Show Input" checkbox is enabled, the Number field based value can come from an external source.
