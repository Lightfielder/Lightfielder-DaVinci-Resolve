# vImageFromClipboard

Grabs, saves, then loads the current clipboard image The "Grab" button is used to capture the clipboard contents. It is a handy way to quickly load an image into the compositing node graph without needing to worry about the filename. This node was designed to work with Fusion Standalone v9 on Windows.
