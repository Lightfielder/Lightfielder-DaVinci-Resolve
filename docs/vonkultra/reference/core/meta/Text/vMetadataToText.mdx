# vMetadataToText

Creates a Fusion Text object from metadata This node is similar to the GetMetadata.fuse with the addition of a "Key" input connection on the node that accepts a Text data type. The "Key" field is used to specify the metadata record. An example of an image metadata record "Key" entry would be the Loader node added attribute of "Filename".
