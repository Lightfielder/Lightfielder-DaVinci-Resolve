# vFileSystemFileSize

Returns the file size This node takes a single filename as a text based input. It checks the file size of the document and returns the value in the unit of measure you specify. The Unit field supports a wide range of file size output scales including: "Byte (B)", "Kilobyte (KB)", "Kibibyte (KiB)", "Megabyte (MB)", "Mebibyte (MiB)", "Gigabyte (GB)", "Gibibyte (GiB)", "Terabyte (TB)", and "Tebibyte (TiB)". The node has two output connections labelled "Output" and "OutputUnit". The "OutputUnit" connection is handy if you need to create a visual overlay with a Text+ node of file size and want to indicate the scale of measure.
