# Lightfielder Projects Folder

## Overview

The "`$HOME/Lightfielder/Projects/`" folder is a convenient place to store Lightfielder's free [downloadable example project files](https://lightfielder.com/docs/Examples/). Having access to several readily available multi-view reference projects is very useful when you want to explore a new concept.

The provided examples can act as "unit tests" if you need to validate the software works as expected on a new workstation deployment. Additionally, the provided examples are helpful as benchmarks when you start comparing the results from different data processing workflows with a consistent, generic stand-in asset.
