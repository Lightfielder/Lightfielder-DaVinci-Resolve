# Lightfielder | Scripts

## 18 Open Lightfielder Folder

This script opens the "`Lightfielder:/`" PathMap which typically expands to the relative folder UNIX path of:  

> `$HOME/Lightfielder/`

![Documentation](images/script_18_Open_Lightfielder_Folder.png)

### Script Usage:

1. Open Resolve. Select the menu item: "Workspace > Scripts > Lightfielder > 18 Open Lightfielder Folder" • OR Select Tool Bar then click "18" button.
